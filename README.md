# Color Magic

A dumpster-and-conveyor color sorter for Kaotic Gaming. Tap a dumpster to pick up its next color stack, then tap where it should go — send it down the track, or swap fronts when a send has no room. A level is cleared when every dumpster holds a single color.

## Play

**[Play Color Magic](https://timleitch.github.io/color-match-game/)** — open in the browser, no account, no install.

Progress is session-only. Refresh and you're back at level 1. This same build will later ship on [Kaotic Gaming](https://kaotic.strictgaming.com); until then, GitHub Pages is the public demo.

You can also open `index.html` locally or serve this folder with any static file server. No build step or dependencies are required.

## Levels

- Track shapes and race formats vary by level.
- Dumpster counts pick from **4, 6, 8, 10, 12, 16, 20** (cap 20). Early levels stay near the low end; bigger yards unlock over time.
- Each map has its own ceiling (oval / figure eight up to 12, diamond up to 16, round square up to 20).
- Color count starts at **4** and can climb to **8** when the yard is big enough.
- Dumpsters ring the outside of the track (including on phones). Cards shrink as the count grows so the track stays visible.
- Dumpsters use 3 sections, each holding up to 50 pieces of one color. Yards are scrambled from a solved deal so they stay solvable.
