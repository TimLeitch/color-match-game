# Color Magic

A dumpster-and-conveyor color sorter for Kaotic Gaming. Click a dumpster to release its next color stack; each piece loops until a matching stack or an empty section can catch it.

## Play

Open `index.html` directly or serve this folder with any static file server. No build step or dependencies are required.

## Levels

- Track shapes and race formats vary by level.
- Each level has a stable randomized 3–10 dumpsters, with 4–5 sections per dumpster.
- Sections contain different stack sizes, including 50-piece waves.
- Best streak and level are saved locally, or to the Kaotic Gaming account when hosted.
