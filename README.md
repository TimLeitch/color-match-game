# Color Magic

A dumpster-and-conveyor color sorter for Kaotic Gaming. Tap a dumpster to pick up its next color stack, then tap the dumpster you want to send it to. The pieces ride the track to that dumpster's dock and land in a matching section with room, spilling into an empty section if needed. A level is cleared when every dumpster holds a single color.

## Play

Open `index.html` directly or serve this folder with any static file server. No build step or dependencies are required.

## Levels

- Track shapes and race formats vary by level.
- Each map sets its own dumpster range (oval 2–12, diamond 3–18, figure eight 3–14, round square 4–30); the ceiling rises over the first ten levels.
- Dumpsters ring the yard without covering the track, and each one docks to the stretch of track facing it. Cards shrink as the count grows.
- Dumpsters have 4–5 sections (3–4 on the biggest maps), each holding up to 50 pieces of one color. About a fifth of sections start empty.
- Color count grows with the map, from 2 up to 6.
- Best streak and level are saved locally, or to the Kaotic Gaming account when hosted.
